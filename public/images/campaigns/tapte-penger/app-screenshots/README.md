# Efero appskjermbilder

Ekte skjermbilder fra mobilappen, klargjort for bruk i markedsmateriell.

- `01-oversikt-anonymisert.jpg`: bedriftsnavnet er endret fra `OCTOSEC AS` til
  `Nordlys Elektro AS`.
- `02-oppdrag.jpg`: ingen kunde- eller bedriftsnavn var synlige.
- `03-tilbud.jpg`: ingen kunde- eller bedriftsnavn var synlige.
- `04-faktura.jpg`: ingen kunde- eller bedriftsnavn var synlige.

Hvis et kundenavn må brukes i senere demonstrasjoner, brukes det fiktive navnet
`Ola Hansen`.

## Versjoner med demoaktivitet

Mappen `med-trafikk/` inneholder markedsversjoner med konsistente, fiktive data:

- Bedrift: `Nordlys Elektro AS`
- Kunder: `Ola Hansen`, `Ingrid Nilsen` og `Fjordgløtt Sameie`
- Tre planlagte eller pågående oppdrag
- Tre tilbud med statusene sendt, utkast og akseptert
- Tre fakturaer med statusene sendt, betalt og forfalt
- Oversikt med moderate summer og én faktura som krever oppfølging

Alle beløp, dokumentnumre, navn og datoer i disse versjonene er demodata.
