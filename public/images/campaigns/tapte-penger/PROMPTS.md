# Promptsett

Bildene ble generert med den innebygde bildegeneratoren. Den opprinnelige
cover-genereringen ble brukt som stilreferanse for bilde 02–12; publiseringsfilen
ligger som `social/01-cover.jpg`.

## Felles art direction

- Bruksområde: `ads-marketing`, vertikalt 4:5 sosialt kampanjebilde
- Premium skandinavisk redaksjonelt uttrykk for norske håndverksbedrifter
- Taktile papirflater, realistiske arbeidsobjekter og minimale linjegrafikker
- Efero-palett: `#f5f7f5`, `#004c3a`, `#00281f`, `#52675f`
- Stor grotesk sans-serif kombinert med kontrollert kursiv serif
- Monospaced småetiketter, god luft og tydelig mobilhierarki
- Ingen vannmerker, uvedkommende logoer, myntsymboler eller stockfoto-klisjeer

## Bildespesifikke prompts

1. **Cover:** «EFERO FELTGUIDE» / «7 steder pengene forsvinner» / «uten at du merker det». Timeliste, kvittering, arbeidshanske, mobil og fakturapapir.
2. **Timer:** «1 / 7» / «Timer ført på hukommelsen» / «10 min glemt hver dag» / «= 3,7 timer per montør i måneden». Timeliste, klokke og blyant.
3. **Materialer:** «2 / 7» / «Materialer som aldri faktureres» / «Smådeler blir store beløp.» Små elektriske komponenter, fester og kvitteringer.
4. **Endringer:** «3 / 7» / «Endringer uten godkjenning» / «Muntlige tillegg er vanskelige å fakturere.» Endringsskjema, snakkebobler og tom signaturlinje.
5. **Dokumentasjon:** «4 / 7» / «Dokumentasjon som mangler» / «Når kunden spør, holder ikke «jeg husker det».» Mobilbilder, sjekkliste og minnekort.
6. **Tilbud:** «5 / 7» / «Tilbud som blir liggende» / «Hvert ubesvart tilbud blir kaldere.» Tilbudsdokument, konvolutt, kalender og mobil.
7. **Fakturering:** «6 / 7» / «Ferdige jobber faktureres for sent» / «Jobben er ferdig. Pengene er ikke på vei.» Ferdig jobbkort, tom faktura og kalender.
8. **Dobbeltarbeid:** «7 / 7» / «Leting og dobbeltarbeid» / «Samme informasjon. Fem steder.» Duplisert jobbkort på papir, mobil og PC.
9. **Regnestykke:** «DET LILLE REGNESTYKKET» / «15 minutter blir 27,5 timer» / «5 ansatte × 15 min × 22 dager» / «= 27,5 timer hver måned». Fem ansattkort, klokke og dagmarkører.
10. **Arbeidsflyt:** «Én jobb. Én arbeidsflyt.» / «Henvendelse» / «Tilbud» / «Jobb» / «Timer» / «Fakturagrunnlag». Fem sammenkoblede kort med enkle linjeikoner.
11. **Sjekkliste:** «HAR DERE KONTROLL?» / «Timer føres samme dag» / «Materialer knyttes til jobben» / «Endringer godkjennes» / «Jobben faktureres raskt». Fire tomme avkrysningsbokser.
12. **CTA:** «EFERO» / «Hvor lekker tiden hos dere?» / «Få tidlig tilgang til Efero.» / «Bli med på ventelisten» / «efero.no/venteliste». Mobil, jobbkort og grønn CTA.
